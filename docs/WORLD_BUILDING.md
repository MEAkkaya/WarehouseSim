# Placing environment objects (collision only, no interaction)

## The short answer
**Make one small scene per object. Do NOT write a script class for it.**

A prop that only has a shape and a collider needs no code. A scene is enough, and
it stays editable in the editor:

```
Bench (StaticBody3D)            <- no script
├─ Model          (bench.glb)   <- your Blender model, instanced
└─ CollisionShape3D             <- a simple box/capsule, NOT the model's mesh
```

Save it as `scenes/props/world/bench.tscn`, then drag that scene into the level as
many times as you like. Change the bench once, every copy changes.

Add a script only when the object DOES something (opens, animates, can be picked
up). Then it gets a class (`class_name`), like Box or Shelf.

## Collision tips
- Use simple shapes (box, capsule, a few boxes for an L-shaped building), never the
  full mesh. It is faster and the player will not catch on small details.
- Let Blender make them: name an extra mesh `Bench-col` (box collider) or
  `Bench-convcol` (convex) and Godot's glTF import builds the StaticBody3D for you.
  `Bench-colonly` makes an invisible collider only.
- Put props on collision layer 1 ("world"), like the walls and the floor.

## Where to put them
Hand-placed props go under the `Props` node inside `scenes/levels/town.tscn`
(or into a room scene for the interior). Group them in sub-nodes (`Props/Street`,
`Props/Factory`) so the Scene tree stays readable.

## Many copies of the same thing (trees, fences, houses)
Hundreds of scene instances are slow. For mass placement use a MultiMesh: many copies
of one mesh drawn in one call, split into ~60 m chunks that are hidden when far away.
`scripts/world/town_builder.gd` does exactly this for the grey-box houses and trees -
copy that approach (or swap its mesh for your own model's mesh).

## Far away things (LOD) and the world edge
- Distance fog (in the World Environment, colour follows the sky) hides pop-in and
  the world edge.
- `visibility_range_end` on a node hides it beyond a distance; for models with a
  low-poly version, `visibility_range_begin/end` on two nodes swaps them (manual LOD).
- Invisible walls close the playable area (see `_build_border` in the builder).


## Editing the warehouse layout
- Walls between rooms: select the `CSGBox3D` nodes in `scenes/levels/warehouse.tscn` (Position / Size in the Inspector,
  Ctrl+D to duplicate; keep "Use Collision" on). Outer walls, hall, office and the roof: `scenes/levels/world.tscn` ->
  `WarehouseShell`.
- Shelf areas are generated by the `StorageRegion` nodes (Z and X are turned 90 degrees: their corridors run east-west).
  Change `corridor_count`, `columns_per_side`, `levels` in the Inspector.
- After moving walls, update `scripts/world/warehouse_layout.gd`: the supervisors' route, the co-workers' loops, the work
  floor rectangles and the lamp rooms are listed there.
